const isFocusedRef = useStopAudioOnBlur(() => { /* 이 화면의 소리를 멈춘다 */ });

### 판단이 필요했던 두 가지

**1. 예약된 재생(기타·냉장고)** — 기타는 정답을 맞히면 1.2초 뒤 다음 문제음이, 냉장고는 정답 뒤 약 0.7초 뒤 다음 문제음이 타이머로 예약됩니다. 그 사이에 탭을 떠나면 **다른 탭에서 소리가 납니다.** 타이머를 지우면 문제 출제가 멈춰 게임이 진행되지 않으므로, **문제 흐름은 그대로 두고 소리만 내지 않는** 포커스 가드를 넣었습니다. 돌아와서 '다시 듣기'를 누르면 들립니다.

**2. 동물게임 루프** — `leftScreenRef`는 **탭을 떠났을 때만** 켜집니다. 탭 안 재생 순서와 간격(matchGame 200ms / orderGame 1300ms)은 한 줄도 건드리지 않았습니다. 소리 3개가 겹쳐 들리는 훈련 설계는 그대로입니다.

### `services/audioCompat.ts` — `pauseAsync()` 추가

동물게임·냉장고가 쓰는 `CompatSound`에 `pause()`가 노출돼 있지 않아 추가했습니다(`player.pause()` 한 줄). 5번(audioCompat 걷어내기) 때 expo-audio의 `pause()`로 1:1 이전됩니다. 세션 2에 넣었다 철회한 `playToEnd()`처럼 재생 타이밍을 바꾸는 메서드가 아닙니다.
