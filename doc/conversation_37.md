## 2. Claude

두 가지가 섞여 있어서 나눠 답한다.

**「보류」로 적힌 것 (인계문 6번)** — 맞다. 그 의미다.
작은 폰(320~360dp)·태블릿 확인은 **그 크기의 기기가 없어서 못 한 것**이고, 세션 36에서 사용자 판단으로 보류했다. 지금 붙어 있는 Note10+(411×868)에서는 세션 35의 반응형 작업이 **기존값 그대로**라 아무것도 검증되지 않는다.

**내가 방금 말한 「실기기 확인」 (인계문 7번)** — 이건 다른 이야기다.
flashcards 작업분은 **지금 있는 Note10+에서도 아직 화면으로 본 적이 없다.** 기기가 없어서가 아니라 코드를 쓰고 아직 안 돌려봐서다. 이 기기에서 볼 수 있는 것들이다:

| 이 기기에서 볼 수 있는 것 | |
|---|---|
| 제목 pill · 진행도 pill | 배경 사진 위에서 과하지 않은지 |
| 진행바 레일이 흰색이 됐다 | 밝은 사진 위에서 오히려 묻지 않는지 |
| 비활성 화살표 #666 | 활성(#333)과 여전히 구분되는지 |
| 「학습완료」 → 배지 애니메이션 | 날아가 멈추는 자리가 배지 한가운데인지 (전에는 70px 아래) |
| 카드 위치 | **868 기기에서는 한 픽셀도 안 바뀌어야 한다** |
| 완료 카드 모달 | 죽은 스타일 20개를 지웠다. 열고 닫고 복원까지 그대로인지 |

기기가 없어서 못 보는 건 그중 **카드 밀어내기의 640dp 폰 케이스**(48px 겹침이 풀렸는지)와 **태블릿 진행바 상한**뿐이다.
