# 점검 이력 — 어느 화면을 언제 훑었나

[`점검표.md`](./점검표.md)로 화면을 훑을 때마다 여기를 손본다.
**목적은 「무엇을 고쳤나」가 아니라 「무엇을 아직 안 봤나」다.**

이 표는 **앱의 UI 파일 전부**(44개 · 14,683줄)를 담는다. 손으로 고른 목록이 아니다 —
빠진 파일은 「안 봤다」로도 안 보이기 때문이다.

## 이 문서는 절반이 갱신, 절반이 누적이다

**섞어 쓰는 게 아니라 나눠 쓰는 것이다.** 어느 절을 손보는지 먼저 본다.

| 절 | 방식 | 왜 |
|---|---|---|
| **화면별** · **한눈에** · **다음 점검 후보** | **갱신** (덮어쓴다) | 「**지금** 무엇을 안 봤나」를 답한다. 누적하면 `flashcards` 줄이 세션마다 늘어나 **안 본 것이 파묻힌다** — 이 문서를 만든 이유가 사라진다 |
| **세션 노트** (아래쪽) | **누적** (아래로 쌓는다) | 「그때 무엇이 나왔나」를 답한다. 덮어쓰면 **같은 파일에서 두 번 다른 것이 나왔다**는 사실이 사라진다 |

> 갱신되는 표에서 사라진 이력은 **세션 노트가 받는다.** 근거 원문은 **그때의 인계문**에 있다
> (세션 49~ `handoff7.md` · 47~48 `handoff6.md` · 43~46 `handoff5.md` · 38~42 `handoff4.md` ·
> 34~37 `handoff3.md`).
> 세 문서가 각각 **지금 상태 · 그때 결과 · 왜 그렇게 했나**를 나눠 갖는다.

## 읽는 법

| 칸 | 뜻 |
|---|---|
| **범위** | 「전수」 = 점검표 일곱 갈래를 다 돌림 · 「부분」 = 그 세션에 만진 자리만 · **빈칸 = 한 번도 안 봤다** |
| **점검 커밋** | 그 점검이 **본 상태**. 이게 있어야 「그 뒤 바뀌었나」를 기계로 판정한다 |
| **터치/`Role`** | 터치 요소 수 / `accessibilityRole`이 붙은 수 (점검표 3절) |

**`?`는 「모른다」다.** 세션 40 이전 점검은 커밋을 남기지 않았다 —
바뀌었는지 알 수 없으므로 **다시 훑어야 하는 것으로 친다.**

## 다시 훑어야 하나 — 판정하는 법

```
git diff --name-only <점검 커밋> HEAD -- <파일>     # 비면 그 뒤로 안 바뀜 = 건너뛴다
git status --short -- <파일>                        # 미커밋 변경도 함께 본다
```

**이 값은 표에 적지 않는다.** 적는 순간 낡는다 — 만날 때마다 돌린다.

**넷 다 세션 40에도 있던 것이다.** `git diff`로 확인했다 — 이번 수정으로 생긴 것은 없다.
즉 **지난번 「전수」가 놓친 것**이고, 큰 것 일곱 개에 가려 눈에 안 들어왔다.

> **한 번 훑었다고 끝이 아니다.** 「전수」는 **그 시점의 전수**이지 파일의 결론이 아니다.
> 큰 것을 걷어내면 그 아래가 보인다 — 그래서 고친 뒤 한 번 더 훑는다.

`index.tsx`가 `<MusicTrainingScreen />` 한 줄이라 **피아노 화면의 일부**다.
피아노가 `guitar` 탭이 아니라 `activity` 탭이라는 것도 여기서 알았다.

## 세션 50 — 드럼 전수 32건 (고침 5 · 0절 1 · 0-2절 26 + 재점검 4)

**사람이 손으로 만지는 마지막 화면이었다.** 범위는 `InteractiveDrumSet`(885 → 895) ·
`drum/index.tsx`(1222 → 1277) · `DrumGameOverScreen`(273) · `drum/_layout`(5) +
UI가 아닌 `hooks/useDrumLogic.ts`(218 → 242) · `constants/drumLayouts.ts`(121) — **2,724줄**이다.

**고친 다섯은 전부 동작이다.** 대비·접근성·치수는 세션 45~49와 같은 기준으로 미뤘다.

| | 무엇이 | 처방 |
|---|---|---|
| **1** | `useDrumLogic`의 다음 라운드 타이머 3개가 아무 데도 안 담겨, 「그만하기」·탭 이탈 뒤에도 **끝난 퀴즈가 혼자 다음 문제로 넘어갔다** | `roundTimersRef`(Set) + `scheduleRoundTimer`. 정답·오답·시간초과 세 갈래의 같은 꼬리를 `scheduleNextRound` 하나로 묶었다 |
| **2** | 점수를 `newScore = score + 1`로 **렌더 클로저에서** 더했다 | `scoreRef` + 유일한 쓰기 통로 `applyScore`. `onGameComplete`는 **터지는 시점의** `scoreRef`를 읽는다 |
| **3** | 카운트다운이 취소되지 않아 도중에 그만둬도 **접은 퀴즈가 `playing`으로** 들어갔다 | `quizRunIdRef` 표 + `quizWaitersRef`(끊을 때 `clearTimeout`과 함께 `resolve`). 접는 길 넷을 **`exitQuiz` 하나로** 모았다 |
| **4** | `Animated.loop` 둘에 정지 참조가 없어, 대기 시간이 지난 뒤 언마운트되면 루프가 **영영 돌았다** (FlatList에 네 벌 산다) | 루프를 바깥 변수에 담아 cleanup에서 `stop()` |
| **5** | 게임 종료 결과창이 조건부 `View`+`zIndex: 2000`이라 뒤로가기가 **탭을 나갔다** | `Modal`(`transparent`·`statusBarTranslucent`·`onRequestClose`). 뒤로가기는 「나가기」와 같은 길 |

> **1·2는 `useDrumLogic.ts`에 있었다.** 화면 이름이 붙은 파일이 아니라 훅이다 —
> **화면 묶음은 `import`를 따라가야 한다**(세션 49 `activity` 탭과 같은 교훈).
>
> **1·2·3·5는 세션 49 피아노의 2·4·2·19와 같은 결함이다.** 골격이 닮지도 않았는데
> 같은 손버릇이 나왔다. **타이머를 안 담고, 클로저로 더하고, 창을 `View`로 만드는 것**은
> 화면과 무관하게 반복된다.

**「그대로」로 정해진 것이 하나 늘었다** — 드럼 위 **마커를 눌러도 소리·제출이 없는 것**(6번).
**0-2절에는 30건이 갔다** — 안 고른 26(🔧 23 · ❓ 1 · 📱 2) + **재점검 4**.

### 이번에 걸리지 **않은** 것

**기타 1번(누를 자리 없는 음 출제)을 드럼에서 세었더니 0건이다.** `useDrumLogic`의
`availableInstruments`(2~5)가 `drumLayouts`의 `order`와 **네 페이지 모두 일치**한다.
채점 연타 빗장 `isAnsweringRef`도 **이미 있었다**(동작 2 통과) — 기타·피아노에는 없던 것이다.
`maxScore` 0 나눗셈은 `clampedMaxScore`가 막고, 오답 문구 `'정답!'` 판별도 정확하다.
`shadow*`·`Platform.OS === 'ios'`도 0건이다.

### 재점검 4건 — 넷 다 이번 수정이 들인 것

`score`를 state와 ref 두 곳에 든다 · 「시작 중」 표가 `isStartingQuizRef`와 `quizRunIdRef`
**둘이 됐다** · `stopPendingRounds`가 이름보다 많은 일을 한다 · 결과 `Modal`의
`statusBarTranslucent`(📱). **규칙 5대로 고치지 않고 0-2절로 보냈다.**

> **세션 47·48·49에 이어 네 번째로 「고치며 들인 것」이다.** 그리고 `score` 이중 보유는
> **기타(48)·피아노(49)에 이어 세 번째**다 — 0-2절이 손버릇 목록이라는 증거가 하나 더 늘었다.
>
> **다만 5번은 그 목록을 처음으로 피했다.** 세션 47·49가 「`Modal`로 감쌌는데 안에
> `absolute`가 남았다」를 두 번 0-2절에 올렸기 때문에, 이번에는 `gameOverOverlay`를
> **바꾸는 김에 `flex: 1`로** 고쳤다. **보류 목록을 읽고 시작하면 같은 줄을 안 만든다.**

**탭 이탈 동작이 바뀐다.** 전에는 퀴즈 모드가 유지된 채 라운드만 혼자 넘어갔다.
`stopAllSounds()`로 소리를 끊는 이상 퀴즈는 이어질 수 없어 **함께 접는 쪽**으로 정했다 —
안 그러면 3번을 고친 뒤 돌아왔을 때 **답을 못 내는 상태로 굳는다.**
