# matchGame AI vs PG 비교

화면은 거의 같고, 안의 학습·통계만 다릅니다.

| | AI | PG |
|---|---|---|
| 파일 | `app/(tabs)/new/(games)/matchGameAI.tsx` | `app/(tabs)/new/(games)/matchGamePG.tsx` |
| 홈 제목 | 청능 훈련 **(Q-Learning)** | 청능 훈련 **(PG)** |
| 학습 데이터 | `qTable` | `policy` |
| 저장 키 | `@AuditoryTrainingApp:gameState` | `@AuditoryTrainingAppPG:gameState` |

둘 다 강화학습입니다. 이름만 다르고 역할이 갈립니다.

- **AI = Q-Learning** — 남은 정답을 상태로 보고 `Q[정답][누른것]`을 갱신
- **PG = Policy Gradient** — 누른 동물의 선택 확률(`policy`)을 갱신

---

## 1. 같은 것 (점수·기회·화면)

점수·기회·난이도 규칙은 같습니다.

- 라운드 시작(`계속하기` 포함)마다 점수 **0**
- 정답: `점수 + (10 × 난이도)`, 오답: 점수 유지
- 기회 3칸, 오답이면 1 감소
- 화면 칩 / 최종 점수 / 전송 payload의 `score`는 모두 `state.score` (그 라운드 값)
- 점수는 라운드끼리 안 쌓임

플레이 중 상태 줄은 공용 칩입니다. (`MatchGameStatusChips`)

```
┌────────┐  ┌──────────┐  ┌────────┐
│ LV 2   │  │ ♥ ♥ ♡    │  │  20점  │
└────────┘  └──────────┘  └────────┘
```

이 칩은 **UI만** 바꿨습니다. 점수·통계 계산은 그대로입니다.

홈 버튼도 같습니다. `표준 모드` / `약점 훈련 모드` / `내 통계 보기`.  
약점의 **의미가 다른데**, 화면 문구는 구분하지 않습니다.

---

## 2. 다른 것 — 통계(`userStats`)

통계 화면은 둘 다 “동물별 정답/시도”처럼 보입니다.  
실제로 올리는 **대상**이 다릅니다.

예시: 정답이 늑대·소·사자인데 늑대를 맞춤.

### PG — 누른 동물

늑대만 `total + 1`, 정답이면 `correct + 1`.  
소·사자는 그대로.

**읽는 법:** 그 동물을 몇 번 눌렀고(`total`), 그중 몇 번이 맞았나(`correct`).  
정답 여부와 상관없이 `total`은 “무엇을 자주 눌렀나”입니다.

### AI — 남은 정답

늑대·소·사자 **전부** `total + 1`, `correct + 1`.  
안 고른 소·사자 통계도 같이 오릅니다.

오답(고양이)을 누르면 고양이 통계는 안 오르고, **남은 정답들**의 `total`만 오릅니다.

**읽는 법:** “이 동물을 잘 맞히나”가 아닙니다.  
“이 소리가 아직 정답으로 남아 있을 때, 이번 선택이 성공했나”입니다.

이 차이는 Q-러닝 루프 안에 통계를 같이 넣어서 생겼습니다.  
`Q` 갱신(남은 정답마다 학습)은 AI 의도이고, `userStats`까지 그 루프에서 올리는 것은 학습과 별개입니다.

통계 화면 문구(“이 동물을 얼마나 맞혔나”) 기준으로는 **PG가 맞습니다.**

---

## 3. 약점 모드와의 연계

고르는 식은 같습니다. `userStats` 정확도가 낮은 동물을 다음 문제로 넣습니다.  
(`total < 3`이면 아직 약점으로 안 봄)

들어가는 **동물이 다릅니다.**

| | 약점으로 잡히는 것 | 다음에 일어나는 일 |
|---|---|---|
| **AI** | 못 맞히고 **남은 정답** | 그 소리를 다시 문제로 냄 |
| **PG** | 잘못 **누른** 동물 | 그 소리를 다시 문제로 냄 |

예: 늑대를 놓치고 고양이만 누름.

- AI 약점 → 늑대·소·사자 (남은 정답)
- PG 약점 → 고양이 (누른 오답)

그래서 로직상으로는 이렇게 볼 수 있습니다.

- AI: 놓친 **정답**을 다시 듣게 함
- PG: 헷갈려서 **고른 것**을 다시 듣게 함

다만 홈 버튼이 둘 다 `약점 훈련 모드`라, 이 차이는 화면에 안 나옵니다.

---

## 4. 한 줄로

| 항목 | AI (Q-Learning) | PG (policy) |
|---|---|---|
| 학습 | 남은 정답 기준 `qTable` | 누른 동물 기준 `policy` |
| 통계 | 남은 정답에 성공/실패를 얹음 | 누른 동물의 횟수/정답 |
| 약점 모드 | 놓친 정답을 다시 출제 | 잘못 누른 것을 다시 출제 |
| 점수 | 같음 (라운드마다 0) | 같음 |
| 화면 설명 | 제목만 다름 | 제목만 다름 |

AI 통계를 화면 의미에 맞추려면, `Q` 루프는 두고 `userStats`만 PG처럼 **누른 동물**에 올리면 됩니다.  
그렇게 바꾸면 약점 모드가 고르는 대상도 PG와 같아집니다.
