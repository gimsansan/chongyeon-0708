# 점검표 — 화면 하나를 훑는 순서

**이 표는 상상해서 만든 것이 아니다.** 세션 34~39에서 **실제로 지적받아 고친 것**을
갈래로 묶었다. 사용자가 자리를 짚어 줘야만 문제가 드러나던 것을, 자리를 안 짚어도
훑을 수 있게 만든 것이 목적이다.

- 쓰는 법: **`/점검 <경로>`** (`.claude/commands/점검.md`), 또는 화면을 만질 때 자동 (`CLAUDE.md` 규칙 5)
- **발견은 고치지 않는다.** 목록으로 보고하고, 고칠 것은 사용자가 고른다
- 어디를 봤는지는 [`점검-이력.md`](./점검-이력.md)에 남긴다
- 새 갈래가 나오면 **여기에 더한다.** 인계문 주의사항이 원문이고, 이 표는 그 색인이다

## 0-2. 보류 — 보고했으나 **아직 안 정한 것**

0절과 다르다. 0절은 「**그대로 두기로 결정**된 것」이고, 여기는
「**보고했는데 고칠지 말지 아직 안 고른 것**」이다. **둘 다 다시 지적하지 않는다** —
같은 것을 또 올리면 사용자가 매번 다시 판단해야 한다.

**「왜 보류」 칸을 본다.** 📱는 **실기기 확인 때 묶어서** 꺼낼 줄이고,

**항목이 여기서 나가는 길은 둘뿐이다.**

- **고쳤다** → 줄을 지운다 (근거는 인계문에 남는다)
- **그대로 두기로 정했다** → **0절로 올린다** (이유와 정한 때를 적는다)

> **여기 있는 것은 다시 묻지 않는다.** 점검이 끝날 때 묻는 것은
> **그 파일에서 새로 나온 것**뿐이다. 이 절을 비우는 일은 실기기 확인 때
> **📱 줄을 묶어서** 따로 한다.
>
> 세션 42까지는 「점검이 끝날 때마다 **이 중 고칠 것 있나를 묻는다**」였다.
> **세션 43에 뒤집었다** — 이미 「나중에」로 정해 둔 것을 점검마다 다시 꺼내면
> 사용자가 **같은 판단을 매번 다시** 해야 한다. 그건 보류가 아니라 미결이다.

## 1. 기준이 틀린 값 — 가장 자주 나왔다

| 볼 것 | 실제로 걸린 것 |
|---|---|
| **개수를 손으로 박았나** | 진행바 눈금 `[0,1,2,3,4,5]` — 카드가 20장이어도 6개였다 (세션 38) |
| **고정 px가 반응형 자리에 있나** | 게이지 `220×40` · 난이도 버튼 `140/160`(360dp에서 40px 넘침) · 카드 밀어내기 `150+70`(640dp에서 48px 잠김) |
| **퍼센트가 무엇의 퍼센트인가** | 레일·마커·눈금이 **기준 셋**이었다. `railPercent()` 하나로 묶었다 (세션 38) |
| **중심 보정이 값에 드러나나** | 마커 `marginLeft: -1` → **`-마커폭/2`** |
| **상자보다 큰 내용** | 마커 상자 32px에 아이콘 36px + `overflow:'hidden'` → 좌우 2px씩 잘림 |
| **개수 0일 때** | 완료화면에서 `1 / 0`이 떴다 |

**확인법** — StyleSheet에서 숫자 리터럴을 훑고, 그 값이 **데이터 개수·화면 폭 중 무엇을 따라야 하는지** 묻는다.

```
grep -n "width: [0-9]\|height: [0-9]\|\[0, 1, 2" <파일>
```

> **값 하나만 보고 단정하지 말 것.** 세션 38에서 「마커가 90%까지만 간다」고 보고했는데
> 그 90은 **레일 폭과 같은 수**였다. 세션 39에서는 「단어 카 드」로 보고 자간인 줄 알았는데
> 실제 문자열은 「단어 카드」였다. **한글·이모지가 섞이면 `od -c`로 바이트를 본다.**

## 2. 대비 — 눈으로는 안 보이고 계산해야 걸린다

| 볼 것 | 실제로 걸린 것 |
|---|---|
| **회색 배경 + 흰 글자** | 「재생 중...」 `borderGray`+`opacity:0.6`+흰 글자 = **1.5:1** · 학습완료 버튼도 같음 |
| **흰 배경 + 옅은 회색** | 되돌리기 아이콘 `textLight`(#999) = **2.8:1** |
| **흰 배경 + 원색** | 등급 색 `#FFD700`·`#7cbd7e` = **2.2:1** (큰 글씨 기준 3:1 미달) |

기준: 본문 **4.5:1**, 큰 글씨/아이콘 **3:1**.
정해진 답: 비활성은 `grayLight` 배경 + `textSecondary` 글자 + `elevation: 0`.
**흰 바탕 초록 글자는 `COLORS.successOnWhite`** — 배경·테두리는 `COLORS.success` 그대로다.

```
grep -rn "#999\|#BDBDBD\|textLight\|borderGray\|opacity: 0\." <파일>
```

## 3. 접근성 속성 — 이 저장소에서 가장 크게 비어 있다

터치 요소에 `accessibilityRole` · `accessibilityLabel` · `accessibilityState`가 있는가.
장식 아이콘에는 **`importantForAccessibility="no"`**.

```
for f in $(grep -rl "TouchableOpacity\|Pressable" app components); do \
  echo "$(grep -c 'TouchableOpacity\|Pressable' $f)	$(grep -c accessibilityRole $f)	$f"; done | sort -rn
```

**수치는 여기 적지 않는다** — 적으면 낡는다. 실측은 [`점검-이력.md`](./점검-이력.md)가 갖는다
(파일마다 「터치/`Role`」 칸, 그리고 「한눈에」 표).

> 훑은 자리에만 접근성이 있다 — **비율과 어느 파일인지는 이력의 「한눈에」가 갖는다.**
> (여기 숫자를 적으면 세션마다 낡는다. 세션 40에 적은 「나머지는 전부 0」이 실제로 틀린 말이 됐다)

**터치를 감싸는 것이 자식을 삼키지 않는지도 본다.** `TouchableOpacity`·`Pressable`은
`accessible`을 끄지 않는 한 **켜져 있고**(RN 0.86 `TouchableOpacity.js:303` —
`accessible={this.props.accessible !== false}`), 켜진 요소의 **자식은 한 덩어리로 묶여**
토크백 초점이 따로 가지 않는다. 모달 배경으로 시트를 감싼 자리가 그랬다 (세션 42).

| 걸리는 모양 | 정해진 답 |
|---|---|
| 배경 `Touchable`이 **시트를 자식으로** 감쌌다 | 배경을 **절대배치 형제**로 내린다 (`components/MissionProgressIcon.tsx`가 그 형태) |
| 눌리지 않는데 `Touchable`로 감쌌다 | 그냥 `View`로. `e.stopPropagation()`은 **RN에서 하는 일이 없다** |

```
grep -n "TouchableOpacity" <파일> | 그 줄의 자식이 화면 한 덩어리인지 본다
```

## 4. RN 골격 — 안드로이드에서만 티가 난다

| 볼 것 | 실제로 걸린 것 |
|---|---|
| 모달이 **`Modal`**인가 | 조건부 `View`+`zIndex`라 **뒤로가기로 안 닫혔다** (익힘모달, 세션 39) |
| `onRequestClose` 있나 | 위와 한 쌍 |
| `ScrollView` padding이 **`contentContainerStyle`**인가 | `style`에 있어 **마지막 항목 아래 여백이 없었다** |
| `maxHeight` 안의 스크롤 상자에 **`flexShrink: 1`** | 0이라 내용이 잘리고 스크롤도 안 됐다 |
| 바닥에 붙는 것에 **`insets.bottom`** | 「전체 다시 하기」가 제스처바에 물렸다 |
| `disabled`인데 **시각 반응만 나는** 버튼 | 학습완료·화살표·「전체 듣기」 |
| 테두리를 상태로 켜나 | **`borderWidth`는 늘 두고 색만 바꾼다.** 아니면 크기가 흔들린다 |

## 5. 죽은 것 · 이름 충돌

| 볼 것 | 실제로 걸린 것 |
|---|---|
| 읽는 곳 없는 state | `completionMessage` |
| 설정 없는 ref의 cleanup | `completionTimeoutRef` |
| 자식이 하나인데 `gap` | `playAllButton`의 `gap: 8` |
| **꺼둔 채 남은 경로** | `PanGestureHandler enabled={false}` (세션 38에 지웠다) |

> 반대로 **꺼둔 코드는 다음 세션이 또 판단해야 하므로** 남기지 않는다.
