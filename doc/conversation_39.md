## 8. Claude

Note10+ 확인 고맙다. 이모지 대신은 **Ionicons 벡터 아이콘**을 추천한다. 이미 이 파일이 `@expo/vector-icons`를 쓰고 있고, 방금 「전체 듣기」·「전체 다시 하기」에 넣은 것과 **한 화면에서 결이 맞는다** — 지금은 버튼만 벡터고 제목·익힘배지·완료화면은 이모지라 섞여 있다.

**이모지가 여기서 불리한 네 가지**

| | |
|---|---|
| **색을 못 바꾼다** | 제목 글자는 `textPrimary`(#333)인데 📖만 컬러라 흰 pill 안에서 혼자 튄다 |
| **기준선이 글자와 다르다** | 지금 `📖  단어 카드`의 **공백 두 개**가 그 어긋남을 손으로 맞춘 흔적으로 보인다 |
| **기기마다 모양이 다르다** | Note10+는 삼성 이모지, 다른 안드로이드는 Noto — 같은 앱이 달라 보인다 |
| **스크린리더가 읽는다** | 「펼쳐진 책 단어 카드」로 들린다 |

**아이콘 후보** — 화면 내용이 *단어 카드*라 책보다 카드 계열이 더 맞는다: `albums`(추천) · `layers` · `book` · `reader`.

**제목만 바꾸면 화면 안이 또 섞인다.** 같이 정리할 후보는 익힘배지 `✅`, 완료화면 `🎉`·`🔄 처음부터` 셋이다.

어느 쪽으로 갈지 알려 달라 — ① 제목만 `albums`, ② 제목만 `book`(뜻 유지), ③ 제목 + 배지·완료화면까지 한 번에. 그리고 **실기기 확인이 끝났으니 지금까지의 익힘모달·버튼 작업을 커밋할까?**

## 10. Claude

`📖  단어 카 드`로 읽었던 게 틀렸다. 바이트로 보면 실제 문자열은 **`📖` + 공백 둘 + `단어 카드`** — 「카 드」 사이 공백은 없고 그냥 낱말 사이 한 칸이다. `letterSpacing` 제안은 근거가 없어졌으니 뺐다.

네 자리를 벡터 아이콘으로 바꾸고 커밋했다 (`dcbe37b`).

| 자리 | 전 | 후 |
|---|---|---|
| 제목 | `📖  단어 카드` | `albums` (primary 주황) + 「단어 카드」 |
| 익힘배지 | `✅ N 개 익힘` | `checkmark-circle` (흰색) + 「N 개 익힘」 |
| 완료화면 | `🎉 학습을 완료하였습니다!` | `trophy` 를 글자 **위에 따로** 세운다 |
| 완료화면 버튼 | `🔄 처음부터` | `refresh` + 「처음부터」 |

넷 다 장식이라 `importantForAccessibility="no"`를 붙였다 — 스크린리더가 글자만 읽는다.
